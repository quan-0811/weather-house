SILVER TO GOLD LAYER TRANSFORMATION DOCUMENTATION
==================================================

This document details the complex transformations applied to each attribute when
converting cleaned Silver layer data to Gold layer data.

Gold layer represents aggregated metrics, feature-engineered data, and ML-ready
features suitable for long-term storage and machine learning models. All
transformations use PySpark for scalability.

IMPORTANT: This transformation includes data enrichment from Open-Meteo API for
New York stations to fill missing data and add additional attributes.

================================================================================
OPEN-METEO API ENRICHMENT (New York Stations Only)
================================================================================

Before aggregation, the silver data is enriched with historical weather data
from the Open-Meteo Archive API for stations located in New York (latitude
40-42°N, longitude -75 to -73°W).

API Data Retrieved (Only to Fill Missing Values):
- temperature_2m, dew_point_2m
- relative_humidity_2m, pressure_msl
- wind_speed_10m, wind_gusts_10m, wind_direction_10m
- precipitation, rain, snowfall
- cloud_cover, weather_code, visibility

Note: The API is ONLY used to fill missing values in existing silver layer fields.
NO new attributes are pulled from the API. All new attributes are derived from
existing silver layer data.

Enrichment Process:
1. Filter silver data for New York stations (latitude 40-42°N, longitude -75 to -73°W)
2. Determine date range from data
3. For each unique station (up to 5 stations), fetch hourly data from API
4. Join API data with silver data on station_id, year, month, day, hour
5. Fill missing values in silver data with API data using coalesce()
   - Only fills NULL/missing values, does not overwrite existing data
   - Only fills fields that already exist in silver layer

Fields Filled from API (when missing in silver):
- temperature_2m: Filled if NULL
- dewpoint_2m: Filled if NULL
- relative_humidity_2m: Filled if NULL
- pressure_msl: Filled if NULL
- wind_speed_10m: Filled if NULL
- wind_gusts_10m: Filled if NULL
- wind_direction_10m: Filled if NULL
- precipitation: Filled if NULL
- rain: Filled if NULL
- snowfall: Filled if NULL
- cloud_cover: Filled if NULL
- weather_code: Filled if NULL
- visibility_km: Filled if NULL (converted from meters to km)

Derived Attributes Created (from existing silver data):
- temperature_dewpoint_spread: temperature_2m - dewpoint_2m
- heat_index: Calculated feels-like temperature in hot conditions (from temp + humidity)
- wind_chill: Calculated feels-like temperature in cold conditions (from temp + wind)
- feels_like_temperature: Best available feels-like (heat_index or wind_chill or temperature)
- precipitation_intensity: Precipitation amount when > 0
- is_raining: Binary flag (1 if precipitation > 0.1mm, else 0)
- is_snowing: Binary flag (1 if snowfall > 0.1mm, else 0)

================================================================================
OUTPUT STRUCTURE
================================================================================

Gold layer produces three main datasets:
1. Hourly Aggregates: Aggregated metrics per hour with time-series features
2. Daily Aggregates: Daily summaries with event flags
3. Monthly Aggregates: Monthly summaries with climatological metrics

================================================================================
PART 1: HOURLY AGGREGATES
================================================================================

Hourly aggregates are created by grouping silver records by:
- station_id, station_name, station_region
- station_latitude, station_longitude, station_elevation, station_timezone
- year, month, day, hour, season

For each group, the following aggregations are computed:

TEMPERATURE METRICS (from temperature_2m):
-------------------------------------------
1. avg_temperature_2m
   - Transformation: Average of all temperature_2m values in the hour
   - Function: avg(temperature_2m)
   - Units: Degrees Celsius (°C)
   - Missing Data: NULL if no valid temperatures in hour

2. min_temperature_2m
   - Transformation: Minimum temperature in the hour
   - Function: min(temperature_2m)
   - Units: Degrees Celsius (°C)
   - Missing Data: NULL if no valid temperatures in hour

3. max_temperature_2m
   - Transformation: Maximum temperature in the hour
   - Function: max(temperature_2m)
   - Units: Degrees Celsius (°C)
   - Missing Data: NULL if no valid temperatures in hour

4. std_temperature_2m
   - Transformation: Standard deviation of temperatures in the hour
   - Function: stddev(temperature_2m)
   - Units: Degrees Celsius (°C)
   - Missing Data: NULL if < 2 observations

5. var_temperature_2m
   - Transformation: Variance of temperatures in the hour
   - Function: variance(temperature_2m)
   - Units: (°C)²
   - Missing Data: NULL if < 2 observations

6. temperature_range (derived)
   - Transformation: max_temperature_2m - min_temperature_2m
   - Action: Calculated from aggregated values
   - Units: Degrees Celsius (°C)
   - Missing Data: NULL if either min or max is NULL

HUMIDITY METRICS (from relative_humidity_2m):
----------------------------------------------
7. avg_humidity_2m

================================================================================
PART 2: TIME-SERIES FEATURES (Applied to Hourly Aggregates)
================================================================================

These features use window functions to compare current hour with previous/next hours:

LAG/LEAD FEATURES:
------------------
38. prev_hour_temp
    - Transformation: Temperature from previous hour
    - Function: lag(avg_temperature_2m, 1) over window
    - Window: Partitioned by station_id, ordered by year, month, day, hour
    - Missing Data: NULL for first hour of each station

39. next_hour_temp
    - Transformation: Temperature from next hour
    - Function: lead(avg_temperature_2m, 1) over window
    - Missing Data: NULL for last hour of each station

40. prev_hour_pressure
    - Transformation: Pressure from previous hour
    - Function: lag(avg_pressure_msl, 1) over window
    - Missing Data: NULL for first hour

41. next_hour_pressure
    - Transformation: Pressure from next hour
    - Function: lead(avg_pressure_msl, 1) over window
    - Missing Data: NULL for last hour

42. prev_hour_wind
    - Transformation: Wind speed from previous hour
    - Function: lag(avg_wind_speed_10m, 1) over window
    - Missing Data: NULL for first hour

43. prev_hour_humidity
    - Transformation: Humidity from previous hour
    - Function: lag(avg_humidity_2m, 1) over window
    - Missing Data: NULL for first hour

44. prev_hour_precip
    - Transformation: Precipitation from previous hour
    - Function: lag(total_precipitation, 1) over window
    - Missing Data: NULL for first hour

TREND FEATURES:
---------------
45. temperature_trend
    - Transformation: Categorical trend indicator
    - Logic:
      - "rising" if current > previous + 1.0°C
      - "falling" if current < previous - 1.0°C
      - "stable" otherwise
      - "unknown" if previous is NULL
    - Units: Categorical string
    - Missing Data: "unknown" if prev_hour_temp is NULL

46. pressure_trend
    - Transformation: Categorical pressure trend
    - Logic: Same as temperature_trend with 1.0 hPa threshold
    - Units: Categorical string
    - Missing Data: "unknown" if prev_hour_pressure is NULL

47. temperature_change_rate
    - Transformation: Rate of temperature change (°C per hour)
    - Formula: avg_temperature_2m - prev_hour_temp
    - Units: Degrees Celsius per hour (°C/h)
    - Missing Data: NULL if prev_hour_temp is NULL

48. pressure_change_rate
    - Transformation: Rate of pressure change (hPa per hour)
    - Formula: avg_pressure_msl - prev_hour_pressure
    - Units: Hectopascals per hour (hPa/h)
    - Missing Data: NULL if prev_hour_pressure is NULL

49. wind_change_rate
    - Transformation: Rate of wind speed change
    - Formula: avg_wind_speed_10m - prev_hour_wind
    - Units: Kilometers per hour per hour (km/h/h)
    - Missing Data: NULL if prev_hour_wind is NULL

================================================================================
PART 3: ROLLING WINDOW FEATURES (Applied to Hourly Aggregates)
================================================================================

These features use rolling windows to compute statistics over multiple hours:

3-HOUR WINDOW:
--------------
50. temp_3h_avg
    - Transformation: 3-hour rolling average temperature
    - Window: Current hour + 2 previous hours
    - Function: avg(avg_temperature_2m) over window_3h
    - Missing Data: NULL if < 3 hours of data

51. temp_3h_std
    - Transformation: 3-hour rolling standard deviation
    - Function: stddev(avg_temperature_2m) over window_3h
    - Missing Data: NULL if < 2 hours of data

52. precip_3h_total
    - Transformation: 3-hour rolling total precipitation
    - Function: sum(total_precipitation) over window_3h
    - Missing Data: 0.0 if no precipitation

53. wind_3h_max
    - Transformation: Maximum wind speed in 3-hour window
    - Function: max(max_wind_speed_10m) over window_3h
    - Missing Data: NULL if no wind data

54. pressure_3h_avg
    - Transformation: 3-hour rolling average pressure
    - Function: avg(avg_pressure_msl) over window_3h
    - Missing Data: NULL if < 3 hours of data

6-HOUR WINDOW:
--------------
55. temp_6h_avg
    - Transformation: 6-hour rolling average temperature
    - Window: Current hour + 5 previous hours
    - Function: avg(avg_temperature_2m) over window_6h
    - Missing Data: NULL if < 6 hours of data

56. temp_6h_std
    - Transformation: 6-hour rolling standard deviation
    - Function: stddev(avg_temperature_2m) over window_6h
    - Missing Data: NULL if < 2 hours of data

57. precip_6h_total
    - Transformation: 6-hour rolling total precipitation
    - Function: sum(total_precipitation) over window_6h
    - Missing Data: 0.0 if no precipitation

58. pressure_6h_trend
    - Transformation: Pressure range in 6-hour window
    - Formula: max(avg_pressure_msl) - min(avg_pressure_msl) over window_6h
    - Units: Hectopascals (hPa)
    - Missing Data: NULL if < 2 hours of data

12-HOUR WINDOW:
---------------
59. temp_12h_avg
    - Transformation: 12-hour rolling average temperature
    - Window: Current hour + 11 previous hours
    - Function: avg(avg_temperature_2m) over window_12h
    - Missing Data: NULL if < 12 hours of data

60. temp_12h_range
    - Transformation: Temperature range in 12-hour window
    - Formula: max(avg_temperature_2m) - min(avg_temperature_2m) over window_12h
    - Units: Degrees Celsius (°C)
    - Missing Data: NULL if < 2 hours of data

61. precip_12h_total
    - Transformation: 12-hour rolling total precipitation
    - Function: sum(total_precipitation) over window_12h
    - Missing Data: 0.0 if no precipitation

24-HOUR WINDOW:
---------------
62. temp_24h_avg
    - Transformation: 24-hour rolling average temperature
    - Window: Current hour + 23 previous hours
    - Function: avg(avg_temperature_2m) over window_24h
    - Missing Data: NULL if < 24 hours of data

63. temp_24h_range
    - Transformation: Temperature range in 24-hour window
    - Formula: max(avg_temperature_2m) - min(avg_temperature_2m) over window_24h
    - Units: Degrees Celsius (°C)
    - Missing Data: NULL if < 2 hours of data

64. precip_24h_total
    - Transformation: 24-hour rolling total precipitation
    - Function: sum(total_precipitation) over window_24h
    - Missing Data: 0.0 if no precipitation

CYCLICAL ENCODING FEATURES:

124. hour_sin
     - Transformation: Sine encoding of hour (0-23)
     - Formula: sin(2 * π * hour / 24)
     - Purpose: Capture cyclical nature of daily patterns
     - Range: [-1, 1]

125. hour_cos
     - Transformation: Cosine encoding of hour (0-23)
     - Formula: cos(2 * π * hour / 24)
     - Purpose: Complement to hour_sin for full cyclical representation
     - Range: [-1, 1]

126. month_sin
     - Transformation: Sine encoding of month (1-12)
     - Formula: sin(2 * π * month / 12)
     - Purpose: Capture seasonal cyclical patterns

127. month_cos
     - Transformation: Cosine encoding of month (1-12)

DERIVED COMFORT INDICES:
------------------------
134. heat_index
     - Transformation: Feels-like temperature in hot conditions
     - Formula: temperature + 0.5555 * (RH/100 * 6.11 * exp(...) - 10)
     - Condition: Only calculated if temperature > 27°C AND humidity > 40%
     - Otherwise: Returns actual temperature
     - Units: Degrees Celsius (°C)
     - Purpose: Human comfort metric in hot weather

135. wind_chill
     - Transformation: Feels-like temperature in cold conditions
     - Formula: 13.12 + 0.6215*T - 11.37*V^0.16 + 0.3965*T*V^0.16
     - Condition: Only calculated if temperature < 10°C AND wind > 4.8 km/h
     - Otherwise: Returns actual temperature
     - Units: Degrees Celsius (°C)
     - Purpose: Human comfort metric in cold weather

136. comfort_index
     - Transformation: Overall comfort index (0-100, higher is better)
     - Formula: 100 - (|temp-20|*2 + |humidity-50|*0.5 + wind_penalty + precip_penalty)
     - Penalties:
       - Wind > 30 km/h: +20
       - Precipitation > 0: +10
     - Range: Clamped to [0, 100]
     - Units: Index (0-100)
     - Purpose: Overall human comfort metric

137. temperature_humidity_index
     - Transformation: Temperature-humidity index (THI)
     - Formula: T - 0.55 * (1 - RH/100) * (T - 14.4)
     - Units: Index (unitless)
     - Purpose: Heat stress indicator

PERCENTILE FEATURES:
--------------------
138. temp_p25
     - Transformation: 25th percentile temperature for station
     - Function: percentile_approx(avg_temperature_2m, 0.25) over station_window
     - Window: Partitioned by station_id
     - Units: Degrees Celsius (°C)
     - Purpose: Lower quartile for anomaly detection

139. temp_p75
     - Transformation: 75th percentile temperature for station
     - Function: percentile_approx(avg_temperature_2m, 0.75) over station_window
     - Units: Degrees Celsius (°C)
     - Purpose: Upper quartile for anomaly detection

140. temp_p10
     - Transformation: 10th percentile temperature for station
     - Function: percentile_approx(avg_temperature_2m, 0.10) over station_window
     - Units: Degrees Celsius (°C)
     - Purpose: Lower decile for extreme anomaly detection

141. temp_p90
     - Transformation: 90th percentile temperature for station
     - Function: percentile_approx(avg_temperature_2m, 0.90) over station_window
     - Units: Degrees Celsius (°C)
     - Purpose: Upper decile for extreme anomaly detection

142. pressure_p25
     - Transformation: 25th percentile pressure for station
     - Function: percentile_approx(avg_pressure_msl, 0.25) over station_window
     - Units: Hectopascals (hPa)

143. pressure_p75
     - Transformation: 75th percentile pressure for station
     - Function: percentile_approx(avg_pressure_msl, 0.75) over station_window
     - Units: Hectopascals (hPa)

144. wind_p90
     - Transformation: 90th percentile wind speed for station
     - Function: percentile_approx(max_wind_speed_10m, 0.90) over station_window
     - Units: Kilometers per hour (km/h)

IQR FEATURES:
-------------
145. temp_iqr
     - Transformation: Interquartile range for temperature
     - Formula: temp_p75 - temp_p25
     - Units: Degrees Celsius (°C)
     - Purpose: Measure of temperature variability

146. pressure_iqr
     - Transformation: Interquartile range for pressure
     - Formula: pressure_p75 - pressure_p25
     - Units: Hectopascals (hPa)
     - Purpose: Measure of pressure variability

ANOMALY FLAGS:
--------------
147. temp_anomaly
     - Transformation: Binary flag for temperature anomaly
     - Logic: 1 if temperature outside 1.5*IQR range (outlier), else 0
     - Formula: (temp < temp_p25 - 1.5*temp_iqr) OR (temp > temp_p75 + 1.5*temp_iqr)
     - Units: Binary (0 or 1)
     - Purpose: Identify statistical outliers

148. pressure_anomaly
     - Transformation: Binary flag for pressure anomaly
     - Logic: 1 if pressure outside 1.5*IQR range, else 0
     - Formula: (pressure < pressure_p25 - 1.5*pressure_iqr) OR 
                (pressure > pressure_p75 + 1.5*pressure_iqr)
     - Units: Binary (0 or 1)
     - Purpose: Identify statistical outliers

149. wind_anomaly
     - Transformation: Binary flag for wind anomaly
     - Logic: 1 if wind speed > 90th percentile, else 0
     - Formula: max_wind_speed_10m > wind_p90
     - Units: Binary (0 or 1)
     - Purpose: Identify extreme wind events

150. extreme_temp
     - Transformation: Binary flag for extreme temperature
     - Logic: 1 if temperature outside 10th-90th percentile range, else 0
     - Formula: (temp < temp_p10) OR (temp > temp_p90)
     - Units: Binary (0 or 1)
     - Purpose: Identify extreme (but not necessarily anomalous) temperatures
